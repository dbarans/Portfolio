# Game dev portfolio — Dominik Barański

**Live:** [dbarans.github.io/Portfolio](https://dbarans.github.io/Portfolio/index.html)

Static portfolio (HTML/CSS/JS), bilingual PL/EN, hosted on GitHub Pages. Projects, links and contact — on the site above.

## Jak tego użyć (workflow z agentami Claude Code)

1. Skopiuj cały folder `agents/` (4 pliki .md) do `.claude/agents/` w
   repo Portfolio.
2. Otwórz Claude Code w katalogu repo Portfolio (upewnij się, że masz też
   dostęp do 3 folderów z kodem gier, np. jako podfoldery lub podane
   ścieżki bezwzględne).
3. Wklej zawartość `master-prompt.md` jako pierwszą wiadomość.
4. Poczekaj na plan od głównej sesji, zaakceptuj albo popraw, zanim
   ruszy dalej.
