Game of Life

High-performance cellular automaton engine for Android · Unity / C#

10,000+ Google Play downloads
O(active region) cost per generation

~0 GC steady-state allocations

Overview

A Conway's Game of Life simulator for Android, built in Unity (C#, IL2CPP) and published on Google Play with over 10,000 downloads. The core of the project is a heavily optimized, multithreaded simulation engine designed to keep large, fast-evolving patterns running smoothly on mobile hardware.

Engine & Performance

Bit-parallel simulation kernel

The world is partitioned into 64×64 chunks stored as ulong bitmasks. Neighbor counts for 64 cells at a time are computed with bitwise full-adders, compiled with Unity Burst as a parallel job.

Active-chunk tracking

Only chunks near cells that changed last generation are recomputed — a step costs O(active region), not O(population). Stable regions cost nothing, no matter how large.

Multithreaded generation pipeline

A background calculation thread runs up to 100 generations ahead of the display, storing per-generation deltas (born / died cells) in a lock-guarded ring buffer instead of full grid snapshots.

Delta-driven incremental rendering

The Tilemap renderer applies only each generation's born and died cells, culled to the camera view — the whole living set is never copied on the hot path.

Procedural grid shader

Grid lines are drawn in a fragment shader on a single camera-following quad: one draw call, constant cost at any zoom, with an LOD fade when zoomed out.

Object pooling

Per-chunk buffers are pooled for near-zero steady-state GC pressure — no allocation spikes or GC hitches on mobile.

Product Features

  • Infinite world — sparse storage of live cells only; pan and pinch-zoom (5×–500×) in any direction.
  • Pattern Book — classic patterns (gliders, oscillators, still lifes) loaded from RLE files with a custom parser and runtime thumbnail rasterization.
  • Save slots — with timestamps, camera state, and generated previews.
  • Interactive tutorial — teaches the rules by having the player draw and evolve patterns.
  • Haptic feedback — native Android vibration bridge with amplitude control.
  • Polished UI — animated with DOTween, adjustable simulation speed up to an uncapped INF mode.
